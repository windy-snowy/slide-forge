# 提示词模板与字段含义

`风格锁定与每页提示词.md` 是给**人看和改**的产物，结构固定为四节；`prompts/page-NN.md` 是
真正发给生图模型的完整提示词。两者同源，都由 `scripts/spec_model.py` 渲染。

## 一、文档结构

```
# <title> · 风格锁定与每页提示词
> 来源说明（预设、受众、用途、页数、画幅、时长）
## 一、风格锁定（Theme Lock v1）      ← 维度/规格 两列表格
**全局负向约束**：……
## 二、全局风格块（每页提示词前都要先粘贴这段）  ← 两个 text 代码块
## 三、逐页提示词（N 页）              ← 每页一个 text 代码块 + 讲者备注引用
## 四、执行记录                        ← 出图/质检状态表，由 gen/qa 回写
```

## 二、逐页提示词块的固定字段

每页块（`page_block()`）固定输出这 8 行，顺序不要改：

| 字段 | 作用 | 写作要求 |
| --- | --- | --- |
| `页面标题` | 画面顶部的主标题 | ≤18 字，一行放得下 |
| `页面目标` | 这一页要让观众得到什么 | 一句话，指导构图的信息焦点 |
| `核心文字` | 必须逐字出现在画面里的文本 | 3–4 条、每条 ≤20 字；**这是 QA 文本比对的基准** |
| `版式结构` | 网格/结构（封面、链路图、矩阵、时间轴、左右对照、仪表盘…） | 相邻页不要同构 |
| `视觉元素` | 具体图形、色彩、标注、连线 | 越具体越好；写清颜色与位置 |
| `风格提示词` | 该页风格一句话 | 默认由 theme_lock 生成 |
| `Logo 规则` | Logo 占位 | 一律"预留干净区域，不生成任何 Logo" |
| `负向约束` | 该页禁止项 | 由全局负向约束继承 + 本页追加 |

## 三、最终提示词是怎么拼的

`page_prompt()` 把四段用空行连接：

```
<global_style_block>
<content_box_rule>            ← 构图安全区：文字图形不贴边、标题整行完整、中文逐字正确
<page_block>                  ← 上面那 8 行
画幅要求：16:9 横版整页幻灯片。
```

顺序与已验证可用的 `glassdeck/gen_relay_slides.py` 完全一致（全局风格 → 安全区 → 页块 → 画幅）。

## 四、为什么要"构图安全区"那一段

图片模型的常见失败是**标题被裁掉**和**中文被生成成伪汉字**。安全区这段同时压住两件事：
- 上下各留 ≥12% 空白、元素不贴边 → 减少裁切风险，也让 16:9 适配时不会切掉内容；
- "中文逐字正确，不得出现错别字、伪汉字或乱码" → 显著降低乱码率。

**不要删掉它**，除非你已经确认该模型在 16:9 下没有裁切问题。

## 五、16:9 与尺寸

- gpt-image 系列没有原生 16:9：用 `size=1536x1024` 出图，再由 `img_providers.to_169()` 适配
  （`fit=auto`：内容能进 16:9 就智能裁切，否则整图放大模糊做底 + 羽化补边，内容零损失）。
- 原生支持 16:9 的后端（如 OpenRouter 的 `aspect_ratio`）直接给 16:9，不需要适配。

## 六、改风格的正确姿势

| 想改什么 | 改哪里 |
| --- | --- |
| 换整套视觉 | `deck_spec.json` 的 `preset` |
| 改配色/字体 | `theme_lock` 对应字段（或加一个新预设 JSON） |
| 改全局语气/约束 | `global_style_block` / `theme_lock.negative` |
| 改某页内容 | `pages[i]` 的 `title` / `core_text` / `visual_elements` |
| 改某页禁止项 | `pages[i].negative` |

改完重跑 `deck.py spec render`，提示词与文档会同步更新。

## 七、新增一个风格预设

在 `references/presets/` 里加一个 JSON（字段照抄现有预设），跑 `deck.py doctor` 会列出可用预设。
`keywords` 决定自动路由能否命中；命中不了的描述会落到 `clean-corporate`。
