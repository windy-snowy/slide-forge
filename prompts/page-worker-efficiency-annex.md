## 效率附录（slide-forge 追加）

在**不违反**本页 prompt 原有规则、不降低对象来源质量的前提下，请按下面的顺序做，以减少图像后端调用次数与总耗时：

### 1. 先用原生对象，再考虑位图
- 矩形、圆角矩形、圆形、直线、带箭头连接线、文本框、表格 → **一律用原生形状/文本框**重建。
- 只有**无法用原生形状忠实表达**的前景视觉（发光弧线、渐变卡片底、图标、徽章、拟物材质）才走图像分离。
- 背景：能用一个原生色块/渐变铺底表达时，**不要**调用图像修复生成 clean base。

### 2. 前景资产合并成最多 2 张 asset sheet
- 把可分离的前景对象按类别合并到 **1–2 张** asset sheet 上一次分离（例如：卡片/容器类一张，图标/徽章类一张）。
- 只有遮罩或抠图质量确实不达标时，才对**个别**对象追加单独一轮图像编辑。
- 页内所有图像任务严格串行（上游要求），不要并行发多个 `editppt image` 调用。

### 3. 单页预算参考
| 页型 | 图像后端调用上限 |
| --- | --- |
| 纯文字/表格/流程图页（可全原生） | 0–1 次 |
| 常规内容页（1 张底图 + 1 张资产表） | ≤ 2 次 |
| 复杂视觉页（渐变卡片 + 图标 + 徽章 + 修复底图） | ≤ 3 次 |

超过上限时，优先降级为原生形状或简化视觉元素，并在 `manifest.json` 的 `warnings` 里如实记录。

### 4. 质量档位
- 结构类资产（背景色块、卡片底、徽章）：`--quality low` 即可。
- 细节类资产（图标线条、发光弧线、拟物材质）：按需 `--quality medium`。
- 只有在对比后发现明显瑕疵时才对**该张**资产提档重做，不要整页提档。

### 5. 失败只修不重派
- 校验失败时，**只重做受影响的产物**，然后重新 `validate` 并 `record`。
- 不要因为超时或未读消息就放弃当前页；也不要把已通过校验的产物整页重生成来"修"另一个无关错误。

### 6. 汇报格式
返回时除了上游要求的固定格式，额外附一行成本摘要：

```
image-jobs: <次数>  |  estimated-cost: <如后端返回则填，否则写 n/a>  |  notes: <一句话说明降级/取舍>
```
